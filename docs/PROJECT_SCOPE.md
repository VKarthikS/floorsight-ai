# Project scope

FloorSight is an independent portfolio project by Venkata Karthik Samula.

This repository contains the working Flask application, automated tests, CI configuration, copyright-safe demonstration assets, and selected engineering experiments relevant to the flooring visualization workflow.

Local secrets, model checkpoints, virtual environments, generated outputs, internal process documents, customer information, and unrelated development material are intentionally excluded from Git.

The Flask and Pillow workflow is the reproducible demonstration path. Gemini rendering is optional and requires a valid user-provided API key. The GCS and segmentation folders represent explored approaches and are clearly labeled as experiments rather than production-ready components.
